# Brave Search MCP

A community server that wraps the Brave Search API, so an assistant can pull
current web results — or local business results — instead of relying only on
what it already knows.

## Why use it

- Ground answers in current information instead of training-data knowledge
- Look up local results (hours, addresses, reviews) for a place or business
- Cheaper and simpler to self-host than most alternative search APIs

## Setup

Get a Brave Search API key and set it as the server's environment variable,
then point your client at the server. Free tier limits are low, so a paid key
is worth it for regular use.
