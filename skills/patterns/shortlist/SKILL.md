# Shortlist

Make many. Keep one.

1. Generate 4-6 genuinely different candidates. Do not refine them yet.
2. State the criteria you will judge on, in one line.
3. Score each candidate against the criteria. One line each.
4. Keep the winner. Refine only that one.
5. Deliver the winner. Name the rejects without explaining them.

Candidates must differ in approach, not just in wording.

Isolate each pass: a subagent where you have them, otherwise a separate pass
in this conversation. Carry forward only the short result, not the working detail.
