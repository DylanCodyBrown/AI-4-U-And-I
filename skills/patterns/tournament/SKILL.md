# Tournament

Compare in pairs. Only winners advance.

1. List the options. Pair them up.
2. For each pair, pick a winner and give the one thing that decided it.
3. Advance the winners. Repeat until one remains.
4. Deliver the champion and the reason it won its final round.

Judge each pair on its own. Do not carry earlier rounds' reasoning forward.

Isolate each pass: a subagent where you have them, otherwise a separate pass
in this conversation. Carry forward only the short result, not the working detail.
