# PDF Review & Extraction, No Add-ons

Reading a PDF doesn't need a connector — Claude Desktop reads an attached
PDF directly, text and (on most plans) the layout of tables and scanned
pages too. A PDF MCP server is for reaching into a *folder full* of them
automatically; for the PDFs already in front of you, attaching is enough.

## How to do it

1. **Attach the PDF(s)** — one at a time or several in the same message if
   you're comparing them.
2. **Ask for the structure you actually need**, not just "summarize this":
   - A table pulled out as clean rows, not a paragraph describing it
   - Every clause matching a keyword ("termination", "liability") with the
     page it's on
   - A side-by-side comparison across two or three attached contracts
3. **Ask it to quote, not paraphrase, anything you'll rely on.** For
   anything you might need to defend later — a number, a date, a clause —
   ask for the exact wording and page reference instead of a summary of it.
4. **Request the output as a file** if you need to keep it — Claude can
   build a `.docx` or `.xlsx` from what it pulled out of the PDF, ready to
   download, rather than leaving it stuck in the chat.

## Good uses

- Pulling every line item off a scanned invoice into a spreadsheet
- Comparing two contract versions for what actually changed
- Answering "does this policy cover X?" against the real document instead of
  from memory
- Turning a long report into a one-page brief with page citations

## Where this hits a wall

A live document store — "check every contract in this SharePoint folder
whenever one changes" — is what an MCP connector is for. Without one, you
attach the specific files you're working on, one review at a time. It won't
watch a folder for you, but it doesn't need to for a one-off review.
